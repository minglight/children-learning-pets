# 寵物聊天系統設計（提案）

> 起因:小朋友回饋「寵物跟主人說話太少了,要有聊天的感覺」。
> **狀態:L1–L4 全部已實作(v13,schema 12→13)。** 本文保留為設計依據與台詞出處;
> 實際台詞以 `app/config.js` 的 `talkCare` 為準(實作時有微調長度),排程與挑選在 `app/room.js`。

---

## 一、為什麼現在「感覺不到在聊天」

看 `app/room.js` 現況,問題不在台詞不夠好,而在三件事:

1. **只有事件回應,沒有主動開口。** 泡泡只在「餵食 / 陪玩 / 摸摸 / 升階 / 訪客」時出現。
   小朋友沒動作 → 寵物完全安靜。閒置時只有兩句撒嬌(`hungryNag` / `playNag`),
   而且條件是 `care.fed === 0`,**餵過之後整天再也不說話**。
2. **沒有記憶。** 每句話都是無狀態的罐頭,昨天做了什麼、上次去誰家玩、
   上次哪一關全對——寵物一概不知道。聊天感 = 對方記得你。
3. **單向。** 寵物講完就沒了,小朋友無法回應。真正的「聊天」需要一來一往。

另外:**進房間時沒有打招呼**(`enter()` 不說話),這是最該有的一句。

⚠️ 版面限制:`A.bubble()` 是**單行不換行**,寬度隨字數線性長。
**台詞請控制在 16 字以內**,最長不超過 20 字。

---

## 二、四層改法（可分批上,L1 零風險）

| 層 | 做什麼 | 動到的檔案 | schema |
|---|---|---|---|
| **L1** | 台詞加量 + 新增閒聊池 | 只有 `app/config.js` | 不變 |
| **L2** | 加觸發點:進房打招呼、閒置閒聊、時段/久違 | `room.js` 少量 | 不變 |
| **L3** | **記憶系統**:寵物記得發生過的事,拿出來聊 | `store.js` + 各寫入點 | **要 migration** |
| **L4** | **回話**:泡泡是問句時出 2–3 個選項鈕 | `room.js` | 不變 |

女兒說的「聊天的感覺」主力在 **L3 + L4**,L1/L2 是打底。

## 三、L3 記憶系統設計

### 3.1 資料結構

新增 `pet.memo`,環狀陣列只留最近 **12 筆**(避免存檔膨脹):

```js
pet.memo = [
  { k: 'visitOut', d: '2026-08-19', mood: 'happy',
    who: '小美', pet: '球球', gift: 'cake' },
  { k: 'clear', d: '2026-08-20', mood: 'proud',
    sub: 'math', lv: 'm3', name: '比多少', perfect: true },
  ...
]
```

- `k` 事件種類、`d` 日期(絕對日期字串)、`mood` **當時的感覺**(← 小朋友特別要的)
- 其餘欄位依種類不同
- **migration**:舊檔沒有 `memo` → 補 `[]`,不從歷史回填(不騙小孩說記得沒發生的事)

### 3.2 記憶事件表

| `k` | 寫入點 | 記錄欄位 | mood |
|---|---|---|---|
| `visitOut` 我去朋友家玩 | `app/visit.js` `enter()` / 給東西後 | `who` 朋友暱稱、`pet` 朋友的物種名、`act` eat/play、`item` 給了什麼 | happy / proud |
| `visitIn` 朋友來我家 | `room.js updateVisit()` leave | `who`、`pet`、`ate` 有沒有一起吃 | happy / fun |
| `giftGot` 朋友的寵物來給我吃/陪我玩 | `PLS_CLOUD.checkVisitLog()` | `who`、`pet`、`act` eat/play、`item` | touched |
| `clear` 過關 | `store.recordRun()` | `sub`(math/eng)、`lv`、`name` 關名、`perfect` 滿分 | proud / excited |
| `favFood` 最常吃的 | `store.feed()` 統計 | `key` 食物 | happy |
| `goldFood` 吃到金色食物 | `store.feed(gold)` | `key` | excited |
| `grow` 長大了 | `store.gainXp()` 升階 | `stage` | proud |
| `newDeco` 抽到新配件 | 升大寶時 | `deco` 索引 | excited |
| `hwRound` 描完一輪 A–Z | `store.submitHwLetter()` | — | proud |
| `redeem` 換了獎品 | `store.redeem()` | `name` 獎品名 | happy |
| `graduate` 有寵物畢業 | `store.graduate()` | `name`、`species` | miss |

### 3.3 記憶台詞模板

閒聊時抽一筆 `memo`,套模板。`{}` 代換。

**去朋友家玩 `visitOut`**(v14:不是送禮,是當場給對方的寵物吃/玩)
- 「上次我們去{who}家,好好玩喔!」
- 「我請{pet}吃{item}耶!」/「我跟{pet}玩{item}!」
- 「{who}家好漂亮,你記得嗎?」
- 「我還想再去找{who}玩~」

**朋友來我家 `visitIn`**
- 「{who}上次來我們家耶!」
- 「我跟{who}一起吃點心,好幸福~」
- 「{who}什麼時候會再來呀?」
- 「我有點想{who}了…」

**朋友的寵物來給我吃/陪我玩 `giftGot`**(v14:東西不會進背包,是牠當場餵了我)
- 「{who}家的{pet}給我吃{item}!」
- 「{pet}帶{item}來陪我玩耶!」

> **舊回憶的相容**:v14 之前記的 `visitOut` / `giftGot` 沒有 `pet` / `act` 兩欄。`memoLine()` 在
> `m.pet` 不存在時會**優先挑用不到 `{pet}` 的句子**(所以每組模板都留了一句),不會講出半截的話。

**過關 `clear`** ← 使用者點名要的:誇獎 + 邀請再去一次
- 「你上次{name}全對耶!好厲害!」
- 「{name}那關你好快,我看呆了」
- 「要不要再去{name}玩一次?」 ← **可點,直接跳關**
- 「我還想看你解{name}!」
- 「你數學已經到第{n}關了耶!」

> 💡 **可點的邀請泡泡**:這類台詞在泡泡上加一個小箭頭,點下去直接
> `PLS.go('quiz', {level})`。做法比照現有的 `_wishRect`(許願泡泡點擊提示)。
> 這是「寵物真的在邀你」而不只是說說,聊天感最強的一招。

**成長 / 配件**
- 「我好像又長大一點點了對不對?」
- 「你看我這個{deco},長大那天拿到的!」
- 「我還小小的,你要牽我喔」(幼幼)
- 「我現在可以保護你了!」(大寶)

**吃的**
- 「我最喜歡{favFood}了,你記得嗎?」
- 「上次那個金色的{key},我還在回味…」
- 「我把最好吃的留到最後才吃」

**其他**
- 「你把 A 到 Z 都寫完了!超厲害」(`hwRound`)
- 「你上次換了{name},開心嗎?」(`redeem`)
- 「我們已經存了{points}個金幣了!」(直接讀 `pet.points`)
- 「我吃過{n}種東西了耶!」(讀 `pet.dex`)

## 四、L1 台詞內容

### 4.1 進房打招呼 `greet`（新增,`enter()` 呼叫）

一般:
- 「你來啦!我等你好久~」
- 「主人~今天過得好嗎?」
- 「嘿嘿,我聞到你的味道了!」
- 「哇!是{暱稱}!」
- 「我一直在看門口耶~」

依時段(`new Date().getHours()`):
- 早(5–11):「早安~我剛剛還在睡耶」/「早安!今天想做什麼?」
- 午(11–17):「午安!你吃飽了嗎?」/「下午好~陽光暖暖的」
- 晚(17–24):「晚上好~我在等你回來」/「今天的星星好亮喔」

久沒來(依 `care` 的日期判斷,**不製造罪惡感**):
- 「好久不見~我有乖乖等你喔」
- 「你回來了!我剛剛在數雲朵」
- 「我把最好的位子留給你了!」

### 4.2 閒聊 `chat`（新增,閒置每 12–20 秒隨機一句）

**自言自語 / 觀察**
- 「今天的雲長得像棉花糖」
- 「窗外有小鳥飛過去了!」
- 「我剛剛好像聽到什麼聲音…」
- 「你有沒有覺得今天香香的?」
- 「我發現地上有一根我的毛…」
- 「這裡的陽光剛剛好耶」

**問主人問題** ← 聊天感關鍵
- 「你今天在學校做了什麼呀?」
- 「你最喜歡什麼顏色?」
- 「你會不會怕黑?我有一點點」
- 「如果我會飛,你想去哪裡?」
- 「你有沒有偷偷想我?」
- 「你覺得我可愛嗎?嘿嘿」
- 「等一下要不要一起玩?」
- 「你想不想聽我做的夢?」

**分享心情**
- 「今天心情亮晶晶的!」
- 「跟你在一起最開心了」
- 「我剛剛做了一個好長的夢」
- 「我夢到我變成一朵雲」
- 「我有點想睡…但我想陪你」
- 「我今天覺得自己變勇敢了!」

**撒嬌 / 親密**
- 「可以再摸摸我嗎?」
- 「我可以靠著你一下下嗎?」
- 「你不要走太遠喔」
- 「你在的時候房間都變亮了」

**傻話 / 冷知識**(小孩最愛)
- 「你知道嗎?我打噴嚏會轉圈!」
- 「我可以看你看很久很久」
- 「我剛剛偷偷練習跳高」
- 「我的耳朵今天特別靈!」

### 4.3 既有台詞加量

現有每組只有 3–4 句,玩幾次就重複。建議各補到 8–10 句:

- `feedStart` 補:「哇~我最愛吃飯了!」「聞起來好香!」「我開動囉,你看我!」
- `feedDone` 補:「這個我要記住!」「主人挑東西好厲害」「下次還要吃這個!」
- `playStart` 補:「這個我玩過!」「準備好了嗎?」「看我的厲害!」
- `playDone` 補:「好累~但好開心!」「下次還要玩喔!」「我們是最強搭檔!」
- `visitPat`、`visitEat` 等訪客組也同樣加量

## 五、L4 回話系統（真正的一來一往）

當寵物說的是**問句**時,泡泡下方浮出 2–3 個回答鈕(帶 emoji,不用太會認字),
點了寵物再回一句。做完就是女兒要的「聊天」。

範例對話組:

| 寵物問 | 小孩選 | 寵物回 |
|---|---|---|
| 你今天過得好嗎? | 😄 超開心! | 耶!那我也開心~ |
| | 😪 有點累… | 那我陪你休息一下下 |
| | 😐 普普通通 | 那我們做點好玩的事! |
| 你最喜歡我哪裡? | 👂 你的耳朵! | 嘿嘿,我每天都有洗喔 |
| | 🥰 你很可愛 | 你才可愛! |
| | 💯 全部! | 哇……我要感動哭了 |
| 你想不想聽我的夢? | 想! | 我夢到我們飛到雲上吃棉花糖 |
| | 等一下 | 好~我先記著,不會忘 |
| 要不要再去{關名}? | 走! | 出發!我幫你加油! → **跳關** |
| | 待會兒 | 好~我等你準備好 |

實作:`chat` 池裡的問句項目改成物件 `{q: '…', a: [{label, reply, go}]}`,
`room.js` 收到有 `a` 的台詞時,在泡泡下方畫選項鈕,沿用既有的 `_xxxRect` 命中判定。

### 實作時跟原企劃不同的地方
1. **選項鈕不放泡泡下方,改放房間下緣中央**。泡泡跟著寵物頭走,鈕放下面會壓到寵物的臉和地墊標籤;
   固定在下緣(跟食物籃/玩具箱同一排)不擋任何東西,位置也穩定好點。
2. **「再去解一次」不是另做一種可點泡泡,而是併進同一套回答選項**(「🚀 走!」/「待會兒」),
   UI 只需要一套繪製與命中判定。
3. **撒嬌機率壓低 + 不連續重複同一句**。第一版實測 40 句裡有 16 句在催「陪我玩」,
   改成沒餵 35% / 沒玩 20%,並加 `pickLine()` 避開上一句,實測降到 6/40、連續重複 0 次。
4. **每種記憶各自設上限**(`MEMO_KIND_MAX`),不只有總數上限——不然餵幾次食就把拜訪/過關的回憶洗光。
