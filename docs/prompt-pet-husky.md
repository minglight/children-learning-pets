這是一個給小學低年級孩子的數學／英文學習 App，叫「寵物小學堂」。
孩子答對題目可以獲得食物和玩具，餵養自己的寵物、把牠養大，最後畢業收藏。

目標裝置：iPad Pro 11 吋，橫向，全螢幕。
使用者：6–9 歲兒童，用手指觸控操作。
氣氛：溫暖、鼓勵、不緊張。答錯不會有懲罰感的紅色警示。

重要：整個 App 的畫面不是網頁，是單一個 HTML canvas，
所有像素都由 JavaScript 的 2D 繪圖指令即時畫出來。
你的設計最後會被人工翻譯成繪圖指令，所以請嚴格遵守下面的技術限制。

## 可以使用
- SVG path（會用 Path2D 直接畫進 canvas，已驗證可行）
- 實色填充、線性漸層、徑向漸層
- 圓角矩形、橢圓、多邊形、貝茲曲線
- 線條描邊（可指定線寬、圓頭/方頭端點）
- 投影（單一顏色 + 模糊半徑 + 位移，不支援 spread）
- 整體透明度

## 不可以使用
- 點陣圖、照片、材質貼圖
- CSS filter、backdrop-blur、mix-blend-mode
- SVG filter（feGaussianBlur 等一律不支援）
- 任何外部資源（字體 CDN、圖片 URL、icon library 的 runtime 引用）
- 新的字體。字體鎖定為 "Andika", "Huninn", "Baloo 2", sans-serif

## 座標與尺寸
邏輯畫布固定 1194 × 834。
1 個畫布單位 = 1 pt，所以你標的座標可以 1:1 抄進程式，請標精確數字。

## 任務：重新設計「哈士奇」這個寵物角色，做出 3 個不同精緻度的方案

### 為什麼是哈士奇
現在 10 隻寵物共用同一組「兩個橢圓（身體 + 頭）」的骨架，只靠顏色和耳朵形狀區分。
結果就是哈士奇看起來不像狗 —— 缺少吻部結構、眉斑／面罩紋路、毛流分區、站姿。
我要先用最難的這一隻試水溫，決定整批 10 隻要走多精緻的路線。

### 請給我 3 個方案，精緻度由低到高
1. 方案 A：維持現在的圓潤幼齒感，但把狗的辨識特徵補上（吻部、眉斑、耳朵）
2. 方案 B：明顯提升結構與細節（毛流分區、面罩、更有重量的站姿），仍然可愛
3. 方案 C：你認為在這些技術限制下能做到的最精緻版本

三個方案要能明顯看出差異，不要只是微調。

### 座標系
原點在角色的水平中心。
腳底（站立地面）固定在 y = +146。
角色總高不得超過 366（含耳朵），亦即 y 範圍約 -220 ~ +146。
水平範圍約 x = -110 ~ +110。

### 每個方案都必須示範以下變體（缺一不可）
1. 三個視角：
   - front  正面（停下／吃／玩時使用）
   - side   3/4 側面（走動時使用；預設朝右，程式會鏡射成朝左）
   - back   背面（往房間深處走時使用；看得到屁股、尾巴、耳朵背面，沒有五官）
2. 兩個成長階段（確認造型在不同尺寸都成立）：
   - 幼幼 ×0.85（另加一根呆毛）
   - 大寶 ×1.12（另戴一款配件）
   縮放的錨點是 y = 146（腳底），不是中心。
3. 大寶配件 5 款：戴在頭部或頸部的裝飾。
   請一併標出配件的掛載座標，因為配件是獨立繪製、疊在角色上的。

### 動態
角色會被程式做擠壓拉伸（呼吸、開心、咀嚼）與整體旋轉（開心轉圈）。
請確保造型是「一團可以被壓扁拉長」的結構，不要有依賴精確比例才成立的細節。

## 請用這個格式交付

除了視覺稿之外，請附上可直接轉成程式的資料：

### 1. 繪製清單（依繪製順序，由後往前）
每一項給我：
- d          SVG path 的 d 字串（座標就用上面指定的座標系，不要另外正規化）
- fill       填色 hex 或漸層定義
- stroke     描邊色（沒有就省略）
- lineWidth  線寬（沒有描邊就省略）
- opacity    透明度（1 就省略）

漸層請寫成：
- 線性：起點 (x,y)、終點 (x,y)、色停站列表
- 徑向：圓心 (x,y)、起始半徑、結束半徑、色停站列表

### 2. 色票
這份設計用到的所有顏色，列成一張表，每個顏色給一個語意化的名字
（例如 fur-base / fur-shadow / mask-dark），不要只給 hex。

### 3. 風格規則
這份設計的內在規則是什麼？請明確寫出數字：
- 線寬有哪幾種？
- 圓角半徑有哪幾階？
- 有沒有統一的描邊？
- 陰影的參數是什麼？
這一段最重要 —— 之後另外 9 隻都要遵守同一套規則，所以規則必須是可執行的
數字，不能是「溫暖」「圓潤」這種形容詞。

### 4. 取材來源（如果有）
若參考了免費授權素材庫，請標明來源與授權條件。
