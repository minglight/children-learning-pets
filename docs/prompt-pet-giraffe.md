這是一個給小學低年級孩子的數學／英文學習 App，叫「寵物小學堂」。
孩子答對題目可以獲得食物和玩具，餵養自己的寵物、把牠養大，最後畢業收藏。

目標裝置：iPad Pro 11 吋，橫向，全螢幕。
使用者：6–9 歲兒童，用手指觸控操作。
氣氛：溫暖、鼓勵、不緊張。答錯不會有懲罰感的紅色警示。

重要：整個 App 的畫面不是網頁，是單一個 HTML canvas，
所有像素都由 JavaScript 的 2D 繪圖指令即時畫出來。
你的設計最後會被人工翻譯成繪圖指令，所以請嚴格遵守下面的技術限制。

## 可以使用
- SVG path（會用 Path2D 直接畫進 canvas，已驗證可行）
- 實色填充、線性漸層、徑向漸層
- 圓角矩形、橢圓、多邊形、貝茲曲線
- 線條描邊（可指定線寬、圓頭/方頭端點）
- 投影（單一顏色 + 模糊半徑 + 位移，不支援 spread）
- 整體透明度

## 不可以使用
- 點陣圖、照片、材質貼圖
- CSS filter、backdrop-blur、mix-blend-mode
- SVG filter（feGaussianBlur 等一律不支援）
- 任何外部資源（字體 CDN、圖片 URL、icon library 的 runtime 引用）
- 新的字體。字體鎖定為 "Andika", "Huninn", "Baloo 2", sans-serif
  （Andika 是識字教學字體，單層 a/g；中文 fallback 到 Huninn）

## 座標與尺寸
邏輯畫布固定 1194 × 834（= iPad Pro 11" 橫向的邏輯解析度）。
1 個畫布單位 = 1 pt，所以你標的座標可以 1:1 抄進程式，請標精確數字。
畫布外緣填色 #E8D9C8。

## 觸控
使用者是 6–9 歲兒童用手指操作。
可點擊元素高度不得小於 66，現有慣例是 84 / 96 / 100。

### C1 — 長頸鹿寵物本體（已實作，附規格供參考）

```
## 已完成：「長頸鹿」寵物角色（app/actors/giraffe.js）

這隻動物是一個獨立的「演員」：不跟任何其他物種共用造型結構。
最大的設計挑戰是脖子——長頸鹿的脖子/身體/頭要連成一條看不出接縫的輪廓，
做法是脖子骨架的起點刻意埋進身體輪廓內部（半寬夠寬蓋住縫），
再沿頸脊補一排鬃毛短刺蓋住那條線，花紋則是「沿骨架點內插」貼在表面，
脖子彎曲時花紋跟著表面走，不會脫離。

### 座標系 / bounds
原點 = 腳底中心，y 軸向上為負。
- top -330（含骨突/耳朵）
- bottom 8
- halfWidth 78

長頸鹿比其他 9 隻明顯高很多（脖子是賣點），但體型（halfWidth）反而比中型犬窄。
`actor-preview.html` 的主畫布如果所有物種共用同一個固定縮放倍率會被裁到看不見頭——
已經改成依各物種 bounds 動態算縮放，其餘物種畫面不受影響。

### 動作表（已實作的 10 個語意動作）
| 指令 | 這隻怎麼演 |
|---|---|
| `idle` | 脖子緩慢 S 型搖擺 + 身體呼吸浮動，尾巴慢速甩動 |
| `walk` | 四足對角步態（暫用一般四足近似，真實長頸鹿是同側前後腳一起動的「側對步」，先求好看不強求生物力學精確），脖子隨步伐輕微前後晃 |
| `eat` | 脖子彎成大 C 型往下往前伸到接近地面，吐出舌尖 |
| `play` | 脖子左右快速甩動 + S 彎，咧嘴笑 |
| `happy` | 脖子後仰拱起、身體彈跳、咧嘴笑露舌尖、頭頂冒兩顆會轉的小星星 |
| `sad` | 脖子低垂下彎、尾巴下垂、單邊眉毛線條下垂 |
| `sleep` | 脖子往後捲，頭靠在自己背上（真實長頸鹿的站睡姿），閉眼 + 冒 zzz |
| `rest` | 脖子微微放低，身體慢慢沉下（`st.settle`） |
| `stretch` | 脖子伸直往上延伸拉長 |
| `greet` | 頭反覆點下又抬起（像連續說「哈囉哈囉」），身體跟著小彈跳，咧嘴笑 + 冒星星（比 happy 幅度小，用來區分「熱情打招呼」跟「過關慶祝」） |

### 節奏參數（已定案）
- `speed` 48 ／ `legFreq` 3.4（腿長，步頻刻意放慢求悠哉感）
- `tailFreq` 1.6 ／ `lean` 0.08（長頸鹿站得直，前傾量比一般四足動物小很多）
- `gait` 'pace'（提示字串，對應真實長頸鹿的側對步，目前繪製尚未真的做出這個步態）

### 三個成長階段（比例差異，非等比縮放）
- 幼幼：頭 ×1.30、脖子只有 ×0.62（還沒完全伸長）、骨突 ×0.45（剛冒出來）、腿 ×0.74、身體 ×0.96
- 小寶：全部 ×1.00（基準）
- 大寶：脖子拉長到 ×1.22、骨突立起 ×1.15、頭比例縮小到 ×0.92（顯得成熟）、身體 ×1.05、腿 ×1.08

### 大寶配件 5 款
戴在頭頂骨突區域（頭部座標系，頸頂端點為原點）：帽子、蝴蝶結、緞帶、花圈、項圈風格各一款。

|---|---|

| 主體亮部 | `#F7E1B3` |

```
## 任務：設計「長頸鹿」的房間場景背景

### 座標系
繪製在 440 × 340 的座標空間裡（程式會等比縮放去填滿實際房間框）。

### 版面切分（硬性）
- y = 0 ~ 160（上方 47%）：背景／牆面／天空。這一段可以放遠景。
- y = 160 ~ 340（下方 53%）：地面。寵物會在這裡走動。
- y = 160 附近是「牆與地的分界線」，必須看得出來，寵物的深度感靠它。

### 硬性規則
- **絕對不可以有前景遮擋物**。寵物會在地面區域自由走動，任何畫在牠前面的
  東西都會穿幫。所有物件都必須在寵物身後。
- 地面區域中央偏上會被程式蓋上兩塊地墊（食物區／遊戲區，各約 280×78 的橢圓），
  請不要在那個位置放重要細節。
- 場景要能承受不同亮度的寵物疊上去，避免大面積的高彩度色塊搶掉主角。

### 創意方向（可調整，僅供起手）
非洲莎凡納草原，白天（跟貓頭鷹的黃昏森林、聖誕橘貓的聖誕紅區隔開，走明亮溫暖路線）：
- 天空：金黃到淺藍的漸層，可以有一兩朵程序化畫的雲
- 遠景：低矮的山丘剪影 + 稀疏的相思樹（Acacia，樹冠是招牌的傘狀剪影）營造縱深，避開地墊區
- 地面：大片金黃草地，可以有稀疏灌木叢或幾撮較深色的草叢點綴

### 風格參考（現有的 4 個場景，新場景要跟它們是同一個世界）
- 象象：向日葵花園，青綠漸層底、葉片散佈、向日葵與雛菊
- 橘橘：聖誕紅底、冬青枝、金色四角星
- 小雞：稻草農場，米黃底、木柵欄、彩旗、程序化散佈的稻草
- 貓頭鷹：黃昏森林，四段漸層天空、徑向月暈、視差山丘、松樹、螢火蟲

### 這個物種的提案主題色（場景要與它協調，最終色號待定案）
wall `#FBEAC8` ／ dot `rgba(184,122,62,0.22)` ／ accent `#C9853E` ／ deep `#8A5A2E`
