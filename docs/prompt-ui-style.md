這是一個給小學低年級孩子的數學／英文學習 App，叫「寵物小學堂」。
孩子答對題目可以獲得食物和玩具，餵養自己的寵物、把牠養大，最後畢業收藏。

目標裝置：iPad Pro 11 吋，橫向，全螢幕。
使用者：6–9 歲兒童，用手指觸控操作。
氣氛：溫暖、鼓勵、不緊張。答錯不會有懲罰感的紅色警示。

重要：整個 App 的畫面不是網頁，是單一個 HTML canvas，
所有像素都由 JavaScript 的 2D 繪圖指令即時畫出來。
你的設計最後會被人工翻譯成繪圖指令，所以請嚴格遵守下面的技術限制。

## 可以使用
- SVG path（會用 Path2D 直接畫進 canvas，已驗證可行）
- 實色填充、線性漸層、徑向漸層
- 圓角矩形、橢圓、多邊形、貝茲曲線
- 線條描邊（可指定線寬、圓頭/方頭端點）
- 投影（單一顏色 + 模糊半徑 + 位移，不支援 spread）
- 整體透明度

## 不可以使用
- 點陣圖、照片、材質貼圖
- CSS filter、backdrop-blur、mix-blend-mode
- SVG filter（feGaussianBlur 等一律不支援）
- 任何外部資源（字體 CDN、圖片 URL、icon library 的 runtime 引用）
- 新的字體。字體鎖定為 "Andika", "Huninn", "Baloo 2", sans-serif
  （Andika 是識字教學字體，單層 a/g；中文 fallback 到 Huninn）

## 座標與尺寸
邏輯畫布固定 1194 × 834（= iPad Pro 11" 橫向的邏輯解析度）。
1 個畫布單位 = 1 pt，所以你標的座標可以 1:1 抄進程式，請標精確數字。
畫布外緣填色 #E8D9C8。

## 觸控
使用者是 6–9 歲兒童用手指操作。
可點擊元素高度不得小於 66，現有慣例是 84 / 96 / 100。

## 任務：風格方向探索（這個階段不要做設計系統）

我要決定這個 App 整體的視覺方向。請給我 3 個明確不同的方向，
每個方向各畫 2 個畫面：

1. quiz（數學答題畫面）
   ── 上方一道題目、中間題目插圖區、下方 4 個答案選項按鈕、
      右上角金幣積分 HUD、連續答對時有 combo 徽章

2. room（寵物房間）
   ── 右側是一個有屋頂的厚木框房間，裡面是 2.5D 空間：
      上半是牆、下半是地板，寵物在地板上走動；
      地板中央有「食物區」「遊戲區」兩塊地墊；
      左側是一欄功能卡片（字母手寫練習、好友、圖鑑…）；
      房間前緣有食物籃／玩具箱可以打開背包

### 這個階段請「不要」做的事
- 不要產出 design token、色票系統、元件庫 —— 那是下一階段
- 不要設計寵物角色本身（另外一條線在處理，先用簡單色塊佔位即可）

### 風格來源：可以取材自免費授權圖庫
我不堅持延續現有風格。你可以從 CC0 / 寬鬆授權的圖庫取材，
模仿它已經自洽的視覺規則（線寬、圓角、透視、配色邏輯），
這比從形容詞發明一個風格穩定得多。

優先考慮 kenney.nl（CC0，免署名，遊戲 UI 導向）與
game-icons.net（CC BY 3.0，單色 SVG）。
三個方向裡可以有一到兩個是這樣來的。

每個方向請標明：取材自哪個來源、授權條件、
以及那個風格的內在規則是什麼（線寬多少、圓角級距、
配色邏輯、有沒有描邊）—— 我要的是規則，不只是樣子。

### 現況參考（現在長什麼樣子）
目前是手繪暖色調：奶油底 #EFE3D2、木框棕 #C99355、
主文字棕 #8A6242、金幣金 #F6C95E、成功綠 #8FC9A8。
按鈕是圓角矩形加淡投影，按下時縮到 0.94 倍。
問題是：515 個顏色各自寫死、沒有統一的圓角/間距/字級規範、
畫面之間沒有轉場、整體比較像教材而不像遊戲。

我想要的是「更像遊戲」—— 但不是變吵、變刺激，
是更有份量、更有回饋感、更值得一直回來看。

## 請用這個格式交付

除了視覺稿之外，請附上可直接轉成程式的資料：

### 1. 繪製清單（依繪製順序，由後往前）
每一項給我：
- 精確座標與尺寸（用 1194×834 座標系）
- 圓角半徑
- fill 填色 hex 或漸層定義
- stroke 描邊色與線寬（沒有就省略）
- 字級與字重
- 陰影參數（顏色、模糊半徑、位移）

漸層請寫成：
- 線性：起點 (x,y)、終點 (x,y)、色停站列表
- 徑向：圓心 (x,y)、起始半徑、結束半徑、色停站列表

若有圖示，請給 SVG path 的 d 字串。

### 2. 色票
這份設計用到的所有顏色，列成一張表，每個顏色給一個語意化的名字
（例如 surface-base / text-primary / accent-warm），不要只給 hex。

### 3. 風格規則
這個方向的內在規則是什麼？請明確寫出數字：
- 線寬有哪幾種？
- 圓角半徑有哪幾階？
- 間距用哪幾個級距？
- 字級有哪幾階？
- 有沒有統一的描邊？
- 陰影的參數是什麼？
這一段最重要 —— 選定方向後所有畫面都要遵守同一套規則，
所以規則必須是可執行的數字，不能是「溫暖」「圓潤」這種形容詞。

### 4. 取材來源
若參考了免費授權素材庫，請標明來源與授權條件。
